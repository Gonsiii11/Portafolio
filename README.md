# Portfolio de Iván Herrera González

Web 3D personal: una moto en primera persona donde los mandos abren las secciones.

## Empezar
```
npm install
npm run dev
```
Abre la dirección que te muestra la terminal (normalmente http://localhost:5173).

## Con Claude Code
Abre esta carpeta con Claude Code. Lee `CLAUDE.md` al empezar, así que ya sabe qué es el proyecto, las reglas (licencia del modelo, tono) y qué queda pendiente. Un buen primer mensaje:

> Lee CLAUDE.md, arranca el proyecto, ábrelo en el navegador y dime qué ves. Después hacemos el primer punto de la lista de pendientes.

## Publicar
Sube la carpeta a GitHub y conéctala a Vercel o Netlify (build: `npm run build`, salida: `dist`).
